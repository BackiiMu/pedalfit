# 페달 테트리스 구현 및 검증

2026-10-26

## 진입과 기능

내 보드 화면 오른쪽 위 게임패드 아이콘 → 보드 스킨 선택 → 게임 시작.

- 10열 × 20행, 7종 블록, 7-bag 순서 생성.
- 자동 낙하, 좌우 이동, 시계 방향 회전과 벽차기, 소프트/하드 드롭.
- 고스트, 홀드(고정 전 1회), 다음 블록 5개(높이가 짧은 화면에서는 3개).
- 줄 삭제, 점수, 10줄 단위 레벨/속도 증가, 최고 기록 별도 로컬 저장.
- 0.5초 고정 지연, 지면에서 이동/회전으로 최대 15회 타이머 리셋.
- 일시정지, 앱 비활성화 자동 정지, 종료 결과와 재시작.
- 터치 버튼과 키보드 조작. 이동/아래 버튼 길게 누르기 반복.
- 등록 보드의 이름과 색상으로 세로 레일 배경 스킨을 선택. 실제 크기·편집 배치는 게임 로직에 사용하지 않음.

## 검증

- Flutter 정적 분석: 문제 없음.
- 전체 자동 테스트 32개 통과 (기존 18 + 게임 14).
- 게임 엔진 9개: 7-bag, 4칸 도형, 벽·바닥·고스트·드롭, I/T 벽차기, 막힌 회전, 홀드, 4줄 삭제/압축/점수/레벨, 중력·일시정지·고정 지연, 리셋 상한, 생성 차단/상단 초과 게임 종료.
- 화면 5개: 320×700 / 844×390 / 1200×900 배치·조작·정지, 생명주기와 기록 저장/재시작/원본 보드 보존, 보드가 없는 홈에서 진입 후 복귀.
- iPhone 17 Pro (iOS 26.5) 시뮬레이터 빌드·실행 성공. 실제 저장 보드 스킨 선택, 게임 시작, 좌우 이동·회전·하드 드롭·홀드에 따른 점수 및 홀드 상태 변경을 접근성 상태로 확인.
- 실제 시작 화면 캡처: tetris-menu.png. 추가 플레이 캡처 도중 Mac이 잠겨 최종 플레이 스크린샷은 저장하지 못함.
- Android 빌드/실기기는 이번 작업에서 검증하지 않음.

## 범위

진행 중 게임의 앱 종료 후 복원, 사운드, 네트워크 순위, T-spin/콤보/백투백 가산점, 줄 삭제 애니메이션은 포함하지 않습니다. 사진 대신 코드로 만든 페달 모양 셀을 사용합니다. 시안의 장식 효과와 실제 화면은 차이가 있습니다.
