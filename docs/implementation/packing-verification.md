# 페달 맞추기 퍼즐

2026-10-27

## 구현

내 보드 → 오른쪽 위 게임패드 → 페달 맞추기. 클래식 낙하 테트리스도 같은 선택 메뉴에서 계속 제공됩니다.

보드/수량/자유·2분 시간 도전 선택 → 실제 크기 드래그 배치와 회전 → 완료/시간 종료 → 결과·새 보드 저장 흐름입니다. 등록 보드가 없으면 프리셋으로 시작합니다. 사용 가능한 카탈로그 제품을 회전/분할 공간에 배치한 해답을 먼저 확보하므로 출제된 목표 수량은 풀 수 있습니다. 작은 보드는 확인된 수량으로 조정하며 아무 페달도 맞지 않으면 시작할 수 없습니다. 64회 후보 구성 탐색은 전역 최대 수량을 보장하는 최적화 알고리즘이 아닙니다.

본체 겹침·보드 밖 배치는 거부하고 대기/기존 위치를 유지합니다. 판정은 실제 mm, 배경 레일은 개략도입니다. 케이블 공간은 제외합니다. 회전·이동·대기로 돌리기·힌트는 되돌릴 수 있지만 힌트/실수 횟수는 줄지 않습니다. 힌트는 한 개를 정답 위치로 옮기고 방해되는 페달을 대기로 되돌립니다.

완료 시간과 별점을 표시하며, 힌트를 사용하지 않은 최고 시간을 규격·수량·모드별로 따로 저장합니다. 다른 문제 구성이 섞일 수 있으므로 동일 스테이지의 온라인 순위와는 다릅니다. 결과는 새 ID로 저장하고 기존 보드는 보존합니다. 저장 실패는 표시하고 다시 저장할 수 있습니다. 진행 중 세션 복원은 포함하지 않습니다.

## 검증

- 전체 테스트 42개: 기존 32개 + 퍼즐 10개.
- 생성기: 5개 보드 규격 × 12개 시드의 해답을 실제 배치하여 경계·겹침 확인. Classic 2는 8개 확보 확인.
- 모델: 겹침/경계 거부, 회전/대기/되돌리기, 힌트, 시간 만료/정지, 완료 후 고정, 새 보드 독립 저장.
- 화면: 320×700, 390×844, 844×390, 1200×900에서 실제 드래그 좌표 변환과 회전·정지. 결과/최고 기록/저장 실패 후 재시도/재시작.
- Flutter 정적 분석과 iPhone 17 Pro 시뮬레이터 빌드·실행 확인.
- `packing-play.png`는 실제 Flutter 위젯의 390×844 테스트 렌더입니다. 검증용 해답 배치를 일부 적용한 화면이며 네이티브 시뮬레이터 캡처는 아닙니다. 코드 기반 페달 그림과 한국어/아이콘 글꼴을 사용합니다.
- Android 빌드와 물리 기기는 이번 작업에서 검증하지 않았습니다.

선택 렌더 재생성(macOS의 시스템 한국어 글꼴과 Homebrew Flutter 경로 사용):

```
flutter test --no-pub --dart-define=CAPTURE_PACKING=true test/packing_screen_test.dart
```
