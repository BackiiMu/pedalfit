# 페달 테트리스: 클래식 테트리스 + 페달 스킨

사용자 수정 반영: 실물 크기 배치 퍼즐이 아니라, 기본 테트리스에 페달 그림을 입힌 게임입니다. 이 문서의 기본 흐름을 Flutter 게임으로 구현했습니다. 실제 구현 범위는 README 및 docs/implementation/tetris-verification.md를 참고하세요.

## 규칙

- 10열 × 20행의 세로 게임판. 배경은 세로로 긴 페달보드 레일입니다.
- I / O / T / S / Z / J / L 7종 테트로미노가 위에서 떨어집니다.
- 좌우 이동, 회전, 소프트 드롭, 하드 드롭, 홀드, 다음 블록, 고스트를 제공합니다.
- 가로 한 줄을 채우면 삭제하고 점수·레벨·속도가 증가합니다.
- 페달 스킨은 그림만 바꿉니다. 충돌 판정은 각 블록의 4개 격자 칸을 사용합니다.
- ㅗ·ㄱ 등의 모양은 페달 그림을 겹치거나 연결해 표현할 수 있습니다. 그래픽의 겹침이 판정 모양을 바꾸지 않습니다.
- 실제 제품의 mm 크기, 케이블 공간, 보드 배치 가능 여부는 게임 규칙에 사용하지 않습니다.
- 등록된 페달보드는 게임판 배경 스킨을 고르는 데 활용하고 게임판 비율은 세로 테트리스 규격을 유지합니다. 저장된 일반 보드 배치는 바꾸지 않습니다.

## 화면 3개

1. 시작: 보드 스킨 선택, 게임 시작, 조작 방법.
2. 플레이: 긴 세로 격자판, 낙하 중인 페달 블록, 쌓인 블록, 홀드/다음 블록, 점수·레벨·지운 줄, 하단 이동/회전/드롭 버튼, 일시정지.
3. 결과: 최종 점수·최고 기록·레벨·지운 줄, 다시 시작·메인으로.

일시정지와 조작 안내는 화면 위 오버레이로 구성할 수 있습니다. 구현 시 회전 규칙·벽차기, 7-bag 생성, 고정 지연, 낙하 시간, 줄 삭제와 점수 규칙을 정하고 검증해야 합니다. 게임 로직과 페달 그래픽을 분리하여 스킨에 따른 판정 차이가 생기지 않도록 합니다.
