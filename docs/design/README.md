기본 내장 image_gen 도구로 생성한 모바일 디자인 검토용 이미지입니다. 실제 Flutter 실행 화면이나 제품 사진 에셋이 아닙니다. 최종 생성 프롬프트는 `concept-01-prompt.txt`에 보관했습니다. 현재 Flutter 구현은 변경하지 않았습니다.

## 참고 서비스와 반영 방향

- [Pedal Playground](https://pedalplayground.com/): 실제 웹 화면의 점 격자 캔버스와 보드·페달 추가 패널 확인. 시안에는 모바일용 보드 캔버스, 확대·축소 도구와 추가 버튼으로 재구성.
- [Pedalboard.App](https://pedalboard.app/): 실제 웹 화면의 보드 갤러리·장르 필터 및 편집기의 Boards/Pedals/Power 도구와 케이블 패널 확인. 시안에는 제품 카드 탐색과 배치·연결 모드 전환으로 재구성.
- [Pedaltrain Pedal Board Planner 소개](https://pedaltrain.com/pages/pedaltrains-pedalboardplanner-com-ios-android-app): 공식 제품 안내에서 보드 계획 및 제품 카탈로그 용도 확인. 해당 서비스의 편집 화면을 직접 검수한 것으로 주장하지 않음.

참고 사이트의 화면·제품 사진을 복사하거나 생성 입력 이미지로 사용하지 않았습니다. 설명한 일반적인 작업 흐름을 바탕으로 새로운 화면을 생성했습니다.

## 화면 구성

1. 보드 편집: 2행 배치, 순서와 케이블 표현, 선택된 페달, 컨트롤, 추가 버튼.
2. 페달 라이브러리: 검색, 카테고리, 페달 카드와 추가 버튼.
3. 페달 상세: 큰 제품 그래픽, 컨트롤과 메모, 보드 추가 버튼.

기존 앱의 짙은 녹색 배경과 민트 포인트를 유지했습니다. 가상 페달은 앱 카탈로그의 Warm Drive, Hard Clip, Velvet Fuzz, Tape Echo, Open Space, Slow Waves를 사용했습니다. 생성된 페달 그래픽은 컨셉 표현이며 실제 제조사 모델을 나타내지 않습니다.

## 구현 전 확인할 사항

자유 배치·연결 모드·확대·회전·복제·메모·보드 저장·상세 화면은 이번 시안에서 제안한 기능입니다. 현재 앱에서 모두 동작하는 기능으로 보지 마세요. 구현 시 실제 화면 크기와 접근성 글자 크기에 맞춰 간격을 조정하고, 글자·아이콘·페달은 개별 UI 요소로 구현해야 합니다. 이 이미지를 화면 전체 배경으로 사용하지 않습니다.
