# 시안 02 — 페달보드 테트리스

주요 목적은 실제 보드 치수 안에 페달을 배치하여 들어가는지 판단하는 것입니다. 기존 사운드 컨트롤 중심 시안 01을 대신하는 제품 방향입니다.

- 보드 너비·깊이를 mm 단위로 지정.
- 모든 페달을 실제 너비·깊이의 공통 배율로 표시.
- 자유 이동, 90도 회전, 복제, 삭제, 확대·축소.
- 제품 본체 겹침, 보드 경계 이탈, 잭·케이블 여유 공간을 구분하여 표시.
- 검색 목록에 페달 치수를 표시하고 사용자 정의 크기 입력 제공.
- 노브 설정·사운드 조절 기능은 주요 작업 흐름에서 제외.

`pedalboard-tetris-concept-02.png`는 내장 image_gen 도구로 생성한 시각적 방향 검토 이미지입니다. 정밀 축척 도면이 아니므로 이미지에서 물리적 적합성을 판단하지 않습니다. 실제 구현에서는 mm 좌표로 경계와 충돌을 계산하고 화면 배율로 변환해야 합니다. 예시 치수는 가상 제품용이며 실물 제조사 제품의 측정값이 아닙니다.

이미지 제작 프롬프트: `concept-02-prompt.txt`. Flutter 코드는 이번 시안 작업에서 변경하지 않았습니다.
