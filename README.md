# PedalFit · 페달보드 플래너 & 게임

실제 보드의 가로·깊이 안에 페달을 배치해 공간을 확인하는 Flutter 앱입니다. mm 단위 배치·회전·충돌 검사와 페달 스킨을 입힌 클래식 낙하 블록 게임을 제공합니다.

## 구현된 화면

1. **내 보드**: 기기에 저장한 보드, 비율을 유지한 썸네일, 이름·모델 검색, 제품 프리셋/커스텀 필터, 복제·삭제.
2. **보드 생성 및 수정**: Pedaltrain 19종 프리셋, 시리즈 선택, 커스텀 가로·깊이·색상과 비율 잠금, 크기 미리보기.
3. **배치 편집기**: 페달 자유 이동, 90도 회전, 복제·삭제, 위치 숫자 입력, 확대·축소, 빈 공간 드래그 및 두 손가락 확대, 5mm 스냅, 실행 취소·다시 실행.
4. **페달 추가 패널**: 실제 모델 프리셋 8종 + 가상 페달 14종, 모델·브랜드·한글 이름·종류·크기 검색, 미니/스탠다드/와이드 필터.
5. **커스텀 페달 패널**: 이름, 본체 가로·깊이·색상, 좌우 잭 여유 공간 입력.
6. **페달 테트리스 게임**: 내 보드 화면 오른쪽 위 게임패드 버튼 → 클래식 테트리스로 진입. 시작/보드 스킨 선택 → 플레이 → 결과. 10×20칸, 7종 테트로미노, 홀드·고스트·드롭·줄 삭제·점수·레벨·최고 기록, 자동 일시정지.

생성 화면의 프리셋·커스텀 두 탭을 각각 포함하면 앞서 제작한 6개 시안의 흐름에 대응합니다. 짧은 가로 화면에서는 캔버스 옆에 설정 패널을 배치합니다.

## 크기와 충돌

- 보드·페달 크기, 위치, 잭 여유는 **mm 단위**로 저장합니다. 표시 배율을 바꿔도 실물 크기는 변하지 않습니다.
- 프리셋은 공식 inch 명목 치수를 mm로 환산한 값입니다. 예: Classic 2는 609.6 × 317.5 mm.
- 빨강: 본체의 보드 경계 이탈 또는 다른 페달 본체와 겹침.
- 케이블 여유 모드의 주황 점선: 회전에 따라 함께 이동하는 잭 여유 공간의 충돌·경계 이탈.
- 잭 좌·우 값은 본체의 기본 방향을 기준으로 하며 90도 회전하면 화면의 상·하 방향으로 회전합니다.
- 페달에 직접 손을 대면 페달이 움직이고, 빈 공간을 드래그하면 캔버스가 움직입니다. 두 손가락 확대는 빈 공간에서 시작하세요.
- 화면 밖으로 이동한 페달은 “보기 및 페달 목록” 메뉴에서 선택하면 다시 찾아갈 수 있습니다.
- 보드를 작게 바꿔도 페달을 자동 축소하거나 옮기지 않고, 기존 mm 좌표를 유지하며 이탈을 표시합니다.
- 프리셋 치수를 수정하면 커스텀으로 전환하여 원본 프리셋 ID를 보관합니다.

레일 그림은 개략적인 시각화입니다. 레일의 실제 폭·간격·부착 가능 영역, 경사와 제조공차, 잭 위치를 실측한 정밀 모델은 아닙니다. 잭 여유 12mm는 수정 가능한 초기값입니다. 가상 페달의 치수도 실제 제조사 모델의 치수로 보지 마세요.

## 저장

상단 저장 버튼을 누르면 보드와 모든 배치를 `shared_preferences`로 이 기기에 저장합니다. 재실행 후 다시 열 수 있습니다. 저장하지 않은 변경이 있으면 돌아갈 때 저장·버리기·계속 편집을 선택합니다. 저장 실패를 사용자에게 알리고, 실패한 저장을 성공으로 표시하지 않습니다. 잘못된 저장 데이터를 읽을 때 기존 데이터를 덮어쓰지 않습니다.

클라우드 동기화와 내보내기·백업 기능은 아직 없습니다. 앱 제거 시 로컬 데이터가 사라질 수 있습니다.

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

2026-10-26 검증 결과:

- 코드 분석: 문제 없음.
- 자동 테스트 **47개 통과**: 실물 크기와 회전, 비대칭 잭 여유의 회전, 본체·잭 충돌 구분, 보드 변경, undo/redo, 로컬 저장 복원 및 손상 데이터 처리, 생성→추가→드래그→확대 후 이동→회전→저장→재열기, 입력 오류와 변경 버리기, 320px/가로/넓은 화면.
- iPhone 17 Pro 시뮬레이터에서 빌드·실행, 실제 보드 생성·페달 추가·저장 확인.
- Android용 프로젝트와 공통 소스는 포함하지만 Android 빌드·실기기 실행은 아직 검증하지 않았습니다. 기존 환경에 Android SDK Command-line Tools가 빠져 있습니다.

실제 배포 전 앱 식별자·서명·표시 이름을 설정해야 합니다. 현재 iOS 식별자는 `com.pedalboard.com`입니다.

## 페달 테트리스 게임

- 이동/아래 버튼은 길게 누르면 반복합니다. 회전은 시계 방향 90도, 홀드는 블록 고정 전 1회, 드롭은 즉시 착지입니다.
- 키보드: ←/→ 이동, ↓ 소프트 드롭, ↑/X 회전, Space 하드 드롭, C/왼쪽 Shift 홀드, P/Esc 일시정지.
- 7-bag 순서, 시계 방향 회전의 벽차기, 0.5초 고정 지연과 최대 15회 리셋을 구현했습니다. 10줄마다 레벨과 속도가 올라갑니다.
- 점수: 1/2/3/4줄 = 100/300/500/800 × 삭제 전 레벨, 소프트 드롭 칸당 1점, 하드 드롭 칸당 2점. T-spin·콤보·백투백 가산점은 포함하지 않습니다.
- 게임 종료 시 최고 기록을 `pedalboard.tetris.best.v1`로 따로 저장합니다. 보드 데이터와 게임 기록은 별개입니다.
- 앱이 비활성화되면 자동 일시정지하며 직접 계속하기를 눌러야 재개합니다. 진행 중인 게임은 앱 종료 후 복원하지 않습니다.
- 등록된 보드는 이름과 색상을 배경 스킨으로 사용합니다. 규격은 모든 스킨에서 10×20칸으로 같으며 기존 편집 배치는 변경하지 않습니다. 보드가 없어도 기본 스킨으로 플레이할 수 있습니다.
- 게임 그래픽은 코드로 그린 페달 외함입니다. I/O는 통짜 페달 하나, 나머지는 두 개로 표현하고 판정은 4칸을 유지합니다. 줄이 지워진 조각도 원래 블록 식별자를 유지해 옆 블록과 합쳐지지 않습니다. 제조사 사진·로고나 생성 시안 이미지를 게임 에셋으로 사용하지 않습니다.
- 주요 소스: `lib/game/tetris_engine.dart`, `lib/game/tetris_screen.dart`. 검증 기록: `docs/implementation/tetris-verification.md`.

## 페달 맞추기 퍼즐

내 보드 오른쪽 위 게임패드 버튼 → **페달 맞추기**. 낙하 테트리스와 별도로 제공하는 실물 크기 배치 퍼즐입니다.

- 등록 보드 선택. 등록 보드가 없으면 Pedaltrain 프리셋 또는 기본 보드 제공.
- 4/6/8개 목표 선택, 시간 제한 없는 자유 모드 / 2분 시간 도전.
- 실제 카탈로그 크기로 겹치지 않는 해답 배치를 먼저 만든 뒤 출제합니다. 요청 수량을 찾지 못한 경우 확인된 수량으로 조정하고 표시합니다. 준비된 페달이 하나도 맞지 않으면 시작을 막습니다.
- 대기 페달을 보드로 드래그, 배치된 페달 재이동, 90도 회전, 대기로 돌리기, 되돌리기.
- 본체 겹침·보드 밖 배치는 거부합니다. 케이블 여유는 게임 판정에서 제외하며 결과 보드에도 0mm로 저장합니다.
- 힌트는 선택/다음 페달을 해답 위치로 옮기고 겹치는 페달을 대기로 되돌립니다. 힌트와 잘못 놓기 횟수는 되돌리기로 취소되지 않습니다.
- 별점·완료 시간·재시작, 규격/수량/모드별 힌트 없는 최고 시간 저장. 문제 구성이 달라질 수 있어 동일 문제 순위표는 아닙니다.
- 완료 결과를 새 보드 ID와 이름으로 저장합니다. 기존 보드 배치를 덮어쓰지 않으며, 실패하면 오류와 재시도를 제공합니다.
- 앱 비활성화 시 자동 일시정지. 진행 중 세션은 앱 재실행 후 복원하지 않습니다.
- 코드: `lib/game/packing_engine.dart`, `lib/game/packing_screen.dart`.

## 앱 아이콘과 iPhone 실행

민트색 페달 4개와 레일로 만든 자체 아이콘을 iOS/iPadOS 및 Android 기본·적응형 아이콘에 적용했습니다. 원본과 1024px 마스터는 `assets/branding/`, 재생성 스크립트는 `scripts/build_app_icons.py`입니다. iOS 19개 참조의 크기·RGB(불투명) 형식을 검증했습니다. Android 5개 밀도를 제공합니다.

실제 iPhone의 홈 화면에서 실행하려면 디버그 대신 릴리스 빌드를 설치합니다. 디버그 빌드는 개발 도구 연결 없이 실행할 수 없습니다. 새 아이콘을 포함한 릴리스 설치를 한 차례 완료했습니다. 이후 통짜 스킨/화면 전환 보강 수정본의 설치 상태는 `docs/implementation/2026-10-27-followup.md`에 기록합니다.

## 디자인 개편 · Paper v1

제공된 `DESIGN-notion.md`를 참고해 따뜻한 종이색 배경, 검정 본문, 얇은 회색 경계, 파란 주 동작으로 개편했습니다. 공통 색상·타이포그래피·버튼·입력창·패널 규칙은 `lib/design/app_design.dart`에 있습니다. 별도 유료/브랜드 전용 글꼴을 복사하지 않고 플랫폼 기본 서체를 사용합니다.

목록·보드 생성·편집·페달 선택·맞추기·낙하 게임의 공통 UI를 통일했습니다. 물리 보드/페달의 색상과 낙하 게임판은 콘텐츠 표현으로 유지했습니다. 미리보기와 변경 내역은 `docs/design/paper-v1/`을 참고하세요.
